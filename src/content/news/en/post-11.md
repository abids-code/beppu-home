B-biz LINK is an organisation set up in 2017 with funding from Beppu City. It aims to create new businesses in Beppu through co-creation with many players and companies, to build a sustainable future for the city, and to improve the city's ability to earn.

We were interviewed for "Innovator Yu", an entrepreneur feature in the B-biz Journal run by B-biz LINK. You can read the article here:
